# Backlog comparativo

Este documento separa referência comercial e trabalho entregue. Ver `../status.md` e `../validacao.md` para validação efetiva.

| Área | Situação desta entrega | Próxima evolução |
|---|---|---|
| Acesso / clínica / equipe | Implementados com sessão, perfis e clínica vinculada | Recuperação de senha, MFA, convites e revogação administrativa |
| Paciente / responsável | Cadastro, ficha, edição API e vínculo administrativo | Edição UI, pesquisa paginada, consentimento versionado |
| Agenda | Criar, listar, concluir, cancelar | Reagendar com controle de versão, recorrência e confirmação |
| Histórico clínico | Registros textuais por tipo, com autoria | Vínculo por consulta e adendos referenciados |
| Anamnese | Texto livre persistido | Campos estruturados, templates e questionário pré-consulta |
| Antropometria | Peso, altura, data e posição | Curvas OMS, prematuridade, indicadores e validação clínica |
| Plano alimentar | Orientação textual manual | Refeições estruturadas, biblioteca licenciada, nutrientes e substituições |
| Relatório | PDF de registros autorizados | Layout clínico validado, assinatura profissional, medidas e filtros |
| Família / diário / mensagens | Portal web por vínculo; registros textuais | Convites, chat em tempo real, avisos e preferências |
| Fotos / exames | Upload e download autenticado | Varredura antimalware, armazenamento externo privado e cotas |
| Terapia / metas | Registro manual do profissional | Jornadas estruturadas e progresso sem automação clínica fictícia |
| Jogos / recompensas | Pendente | Conteúdo original supervisionado e avaliado |
| Financeiro / assinaturas | Pendente | Lançamentos, entitlements e integração real de pagamento |
| Aplicativos / PWA | Web responsiva | Manifest, instalação e push; sem cache offline de dados de saúde por padrão |
| Comercial / multiclínicas | Escopo por clínica no núcleo | Onboarding, provisionamento e testes de escala |
